# Sahil Dalvi – Portfolio Website

Hi, I'm **Sahil** 👋 — a Computer Science graduate and Frontend Developer from India.

This is my personal portfolio website. It shows who I am, the skills I have, and the projects I have built. The site has smooth animations, a custom cursor, and works well on both mobile and desktop.

---

## ✨ What's Inside the Website

- **Loader screen** – a short intro animation when the site opens
- **Hero section** – a big welcome section with my name and role
- **About** – a short introduction about me
- **Projects** – my best work, with links to the live websites
- **Skills & Toolbox** – the technologies I use
- **Experience** – my work and learning journey
- **Contact** – LinkedIn link, resume download, and a WhatsApp button
- **Extras** – scrolling tech banner, custom cursor, and scroll animations

## ⚙️ How to Run This Project on Your Computer

### 1. What you need first
- [Node.js](https://nodejs.org/) (version 18 or newer)
- [Git](https://git-scm.com/)

### 2. Steps

```bash
# 1. Download the project
git clone https://github.com/Sahild12/sahil-portfolio.git

# 2. Go into the project folder
cd sahil-portfolio

# 3. Install all the packages
npm install

# 4. Start the website
npm run dev
```

Now open the link shown in your terminal (usually `http://localhost:5173`) in your browser. 🎉
